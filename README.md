# AllPremiumBro

Landing page satu file untuk AllPremiumBro (allpremiumbro.store).

Jual X Premium dan Telegram Premium model **gift** (bukan share akun), order lewat Telegram.

## Cara deploy

File ini statis total. Gak ada build, gak ada dependency, gak ada backend.

1. Ambil `index.html`.
2. Taruh di root hosting statis apa aja (GitHub Pages, Cloudflare Pages, Netlify, Vercel, atau server sendiri).
3. Arahkan domain `allpremiumbro.store` ke situ.

Selesai.

## Isi

- `index.html` - website lengkap (HTML, CSS, JS inline). Cuma load Google Fonts dari luar.
- `MASTER.md` - catatan design system aktif (neo-brutalism).
